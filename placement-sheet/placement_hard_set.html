Quant puzzles you code yourself

Quant firms (Jane Street, Optiver, Citadel, Tower, Quadeye, Graviton, AlphaGrep, IMC, HRT) love probability and expected-value questions, and their tests often want you to compute the answer, not just guess it. For each one: first write an exact solution (DP, Markov chain, or maths), then write a quick Monte Carlo simulation and check that both agree. Where a known answer exists it is given so you can verify.

What's coming next

Since question banks leak, companies keep moving to problems that combine two ideas, or that need you to see a hidden structure. These are the patterns that have been showing up more and more, and the ones most likely to appear in your test. Each card links straight to practice problems from this sheet.

How to use this sheet

  1. Pick your daily count in the Daily plan tab. 12 a day finishes the whole sheet in about a month.
  2. Press Start on a problem. A timer appears at the bottom with that problem's time budget. If it turns red, you are over time.
  3. Code it fully and submit it on LeetCode, Codeforces or CSES. Only press Solved when the judge says Accepted. That is the only honest signal.
  4. Stuck at the time limit? Press Gave up. The problem gets a Revisit tag. Read the editorial, then re-solve it from scratch two or three days later without looking.
  5. Do it in OA conditions. One sitting, no autocomplete help, no looking up solutions mid-problem. Write your own template code (segment tree, DSU, modpow, Dijkstra) beforehand so you can paste it, like you would in a real test.
  6. Click a status chip any time to cycle it: To do → Solved → Revisit → To do.

A good daily rhythm

  • Block 1 (about 90 min): the T1 problems. Speed run. Aim to beat the clock on every one.
  • Block 2 (about 2 hours): the T2 problems, like a mock OA.
  • Block 3 (whatever is left): the T3 boss problems. Even partial progress here sharpens you.
  • End of day (20 min): re-solve one Revisit problem from an earlier day.

Progress is saved in this browser only. If you clear site data or switch devices, it starts fresh.
